# Space Climate AI

## Integrante

Ricardo Batah Leone

## Descrição

Projeto desenvolvido para a Global Solution 2026.1 da FIAP.

A solução demonstra como a Inteligência Artificial pode auxiliar na interpretação de dados climáticos provenientes do ecossistema espacial.

## Problema

Satélites geram grandes quantidades de dados climáticos diariamente. A análise manual dessas informações pode ser lenta e dificultar a tomada de decisão.

## Solução

A plataforma utiliza Inteligência Artificial para transformar dados climáticos em relatórios automáticos e de fácil compreensão.

## Tecnologias Utilizadas

- Python
- Inteligência Artificial Generativa
- APIs Climáticas
- GitHub

## Estrutura do Projeto

- docs
- images
- services

## Objetivo

Demonstrar a aplicação de IA e análise de dados em soluções relacionadas à economia espacial.
