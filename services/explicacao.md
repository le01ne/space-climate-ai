# Explicação do MVP

O MVP desenvolvido para o projeto Space Climate AI demonstra uma aplicação simples de Inteligência Artificial para análise climática.

O sistema utiliza dados climáticos simulados, como temperatura e umidade, para gerar automaticamente um relatório textual.

Essa abordagem representa uma prova de conceito de como sistemas baseados em IA podem auxiliar aplicações relacionadas à economia espacial e monitoramento ambiental.

Fluxo do sistema:

Dados Climáticos
↓
Processamento
↓
IA Generativa
↓
Relatório
